# Air Monitor Lite / CGDN1

ESP32-порт с локальным интерфейсом UI25. Основан на
[nemethhh/esphome-qingping-cgdn1](https://github.com/nemethhh/esphome-qingping-cgdn1),
дополнен локальным меню, настройками и экраном обновления.

Обычный персональный UI25 проверен на реальном CGDN1 с заводской `4.5.8`:
передача app, первый запуск, защищённый native API, CO₂, температура,
влажность и подключение Home Assistant. Это проверка базового порта.
06.11.2026 также успешно пройден полный HACS/Web Bluetooth мастер с публичным
персонализируемым шаблоном на CGDN1 `4.5.8` / HW `0001`: прибор загрузился,
ESPHome в HA перешёл в loaded и передал живые CO₂/T/RH. Мастер остаётся beta;
результат не распространяется автоматически на другие аппаратные профили.

В публичной сборке используется Inter по OFL вместо системного Tahoma.
Разметка и алгоритмы UI25 сохранены; точное совпадение глифов не заявляется.
PM-переключатель приостанавливает чтение и запрашивает GPIO13; физическая
остановка вентилятора на каждой ревизии платы не подтверждена.

Сборка: Python 3.12/3.13, виртуальное окружение, зависимости из
`requirements.txt`, затем `python tools/build_lite.py` из корня репозитория.
Скрипт не прошивает прибор. Результат — нерабочий публичный шаблон: его
обязательно персонализирует интеграция перед передачей.

Заводской загрузчик и таблица разделов сохраняются. Это не полный backup:
последующие OTA могут перезаписать второй слот. Не применять этот образ
к Monitor 1, Monitor 2, CGS1 или похожему устройству.
